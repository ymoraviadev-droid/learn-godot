# Vision

## What

A Hebrew tutorial book/course on Godot game development with C#, built as a web-based editor and reader.

## Why

- Learning Godot (C#) by writing a tutorial — teaching is the best way to learn
- Hebrew-language resource for Godot is practically nonexistent
- The act of translating concepts into Hebrew deepens understanding

## Who

- **Author**: Single writer (you), using the editor to create and organize content
- **Readers**: Hebrew-speaking developers and hobbyists who want to learn Godot with C#

## Goals

- Rich, beautiful articles with code highlighting, images, and full formatting
- RTL-first design for Hebrew content
- Simple authoring workflow — open the app, write, save
- Read-only sharing — readers get a polished, static experience
- Content versioned in git alongside the app

## Non-Goals (for now)

- Multi-user editing
- User accounts or authentication
- Comments or community features
- Hosting a backend server
